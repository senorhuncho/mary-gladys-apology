# For Mary Gladys ♥

A private romantic apology experience from Jason to Mary Gladys.

The site is a lightweight static build with:
- animated envelope opening
- cinematic scene transitions and reveals
- an original ambient soundtrack generated in the browser
- automatic and manual story navigation
- the full original apology letter
- a final interactive heart sequence
- responsive iPhone/Safari and desktop layouts
- reduced-motion accessibility support

## Deploy to Vercel

[Deploy with Vercel](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fsenorhuncho%2Fmary-gladys-apology&repository-name=mary-gladys-apology)

No framework or build command is required. Vercel can serve the repository as a static site directly.
